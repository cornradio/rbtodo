# RBTodo Release Notes

## v1.2.0 — 2026-10-11

### ✨ 新功能

- **手动保存（Quick Panel）**：编辑不再自动远程保存；底部提供云下载 / 保存图标按钮，支持 `⌘S` / `Ctrl+S`。切换 todo 或 ESC 关闭时，有未保存改动才会上传，并弹出 Saved 提示。
- **直接覆盖远程**：Save 不再触发 CONFLICT 合并文本（不传 `expectedUpdatedAt`）。
- **iOS 风格主题**：新增 Dusk / Ocean / Forest / Midnight / Aurora / Blossom；默认 Dusk。

### 🛠 改进

- 已完成 todo 只变灰，不再划线。
- 对号按钮只插入复选框，不再附带 `item` 文字。
- 颜色按钮 `A` 垂直对齐修正。

## v1.1.0 — 2026-07-02

### ✨ 新功能

- **放大编辑模式（Zoom Editor）**：工具栏新增 ⛶ 按钮，点击后隐藏顶部栏、标题、左侧任务列表和底部状态栏，让文本编辑区填满整个窗口，专注写作。工具栏自动悬浮到右上角，鼠标移到顶部才显示，移开自动隐藏。再点 ❐ 或按 Esc 退出放大。
- **可配置放大快捷键**：默认 `⌘L` / `Ctrl+L` 切换放大模式，可在 Settings → Shortcut → "Zoom Editor Shortcut" 录制自定义快捷键。
- **Esc 键智能退出**：放大模式下按 Esc 先退出放大，再按才关闭当前 todo，避免误操作。
- **左右键跨周导航**：在非编辑状态下按左右方向键切换日期时，到达最左端（«）后再按左键会进入上一周，日历旁显示 `[-1]` 标识，可无限向前回溯。按右键可逐步回到本周，也可点击 ↩ 按钮一键跳回今天。
- **右键选中文本创建 Todo**：在编辑器中选中文字后右键，菜单显示「创建 Todo」选项，点击后自动以选中文字作为标题和内容创建新 todo。新 todo 内容顶部会标注来源 todo 的标题和 ID，方便溯源回查。

### 🛠 改进

- **搜索支持 ID**：搜索框现在支持按 Todo UUID 搜索，解决重名 todo 难以定位的问题。搜索结果右侧显示短 ID（前 8 位），点击可复制完整 ID。
- **托盘图标交互（macOS）**：左键点击托盘图标展开/隐藏面板，右键才弹出菜单。旧版本左右键都弹菜单，体验不佳。

## v1.0.4 — 2026-06-05

### ✨ 新功能

- **闲置自动隐藏**：面板在无操作 N 分钟后自动保存并隐藏（默认 5 分钟，设置中可改，设为 0 关闭）。📌 钉住时不生效。适合多设备协作，防止 AFK 时本地持续向云端同步覆盖其他实例。

### 🐛 Bug 修复

- **粘贴图片后 ESC 图片丢失**（首次粘贴到空 todo 时必现）—— 根因：panel-shown 刷新 `todos[]` 数组后，`editingTodo` 变成孤立引用，之后的编辑/保存都写在孤立对象上，而用户重新点击 todo 从 `todos[]` 取到的是旧数据。修复：panel-shown 时无论本地/远程都重新同步 `editingTodo` 引用到新数组，并先 flushSave 再 reload。
- **粘贴图片立即强制保存**：图片上传完成后直接 `await flushSave()`，不再依赖 200ms debounce，消除时序窗口。

## v1.0.3 — 2026-06-04

### ✨ 新功能

- **界面缩放**：`⌘+` / `⌘-` / `⌘0` 调整整体大小（字体、按钮、间距同比缩放），范围 60%–200%，自动保存。
- **设置面板双栏布局**：左栏分类（Theme / Server / Toolbar / Shortcut / System / Projects），右栏显示对应内容，更清爽。
- **跨日提醒**：每分钟检查一次日期，若跨过午夜会提示 `按 ⌘R 刷新日期`，⌘R 会重载页面更新今天/本周 tab。
- **⌘⇧V / Ctrl+Shift+V**：在编辑器内按下直接以纯文本粘贴（去除一切格式）。
- **右键 A 按钮**：直接套用上次使用的颜色到选中文字（不弹颜色选择器），A 按钮颜色变为上次选的色作为视觉提示，跨重启记忆。

### 🛠 改进

- **设置整理**：Emoji List / Date/Time Format / Custom JS 三项合并为一组 "Toolbar Customization"。

### 🐛 Bug 修复

- 勾选 todo 完成后再次打开有时变成未勾选 —— 由于 `editingTodo` 引用与列表数组解耦后未同步 `completed`，被自动保存的旧值覆盖。
- **按 ESC 有时内容没保存** —— 旧实现用同步 XHR，在某些场景（特别是带 auth 的远程服务器）会静默失败，fallback 又带不齐 header。改为异步 `flushSave()`，保存完成再关闭编辑器。
- **code block 保存格式错误** —— flushSave 用了原始 `innerHTML`，把 CodeMirror 控件的整坨渲染 DOM 都存了；改为 `getEditorHTML()`，code block 正确序列化为 `<pre>` + 代码文本。

## v1.0.2 — 2026-06-02

### ✨ 新功能

- **⌘F — 当前 todo 内查找**：编辑器右上角浮出搜索条，实时高亮匹配（黄色背景，当前激活项橙色），显示 `N/M` 计数，Enter 跳下一个 / Shift+Enter 上一个，ESC 关闭。若有选中文本会自动填入。
- **⌘O — 全局搜索 todo**：把原本的 ⌘F 全局搜索改成 ⌘O（避免和文档内查找冲突），更符合常见编辑器约定。
- 顶部 🔍 按钮 tooltip 同步更新为 `Search todos (⌘O)`。
